# Spotify Clone 🎵
## 🔗 Live Demo

[View Spotify Clone](https://iambasicallysania.github.io/spotify-clone/)

A Spotify-inspired music player website built using HTML and CSS.

## 📌 About the Project

This project is a frontend clone of Spotify's web interface. 
I created it to practice and improve my HTML and CSS skills by recreating the layout and design of Spotify.

## 🚀 Features

- Spotify-inspired dark UI
- Sidebar with Home, Search and Your Library
- Recently Played section
- Trending music cards
- Featured Charts section
- Music player at the bottom
- Playback controls
- Volume control
- Responsive card layout

## 🛠️ Technologies Used

- HTML5
- CSS3
